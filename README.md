<details>
<summary><b>🦋 B-FLARE</b> — Butterfly-based Leverage &amp; Activation Recommendation Engine &nbsp;<code>TypeScript</code></summary>
<br/>

```text
   Overview ──► Intelligence ──► Butterfly ──► Intervention ──► Impact
      │              │              │               │              │
   readiness      corridors     seed cluster     nudge users     cascade
    scores        & matches    (minimal set)    idle→ride made     (BER)

   Ride Opportunity = Route × Time × Detour × Capacity × Recurrence
   BER              = New Active Users from Seed Cohort ÷ Seed Users
```

An AI-powered community activation prototype for **FellaRide**. It finds the smallest, highest-leverage group of commuters (a connector, a driver and a few passengers) whose activation can trigger a self-growing carpooling network, then tracks the cascade as a Butterfly Effect Ratio. Runs on synthetic data as a prototype.

`React 19` · `TypeScript` · `Vite 6` · `Tailwind CSS 4` · `Framer Motion` · `Gemini API`

[**→ View repo**](https://github.com/mdshameel/B-FLARE-Butterfly-based-Leverage-Activation-Recommendation-Engine)

</details>
